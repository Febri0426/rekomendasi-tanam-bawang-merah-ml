# 🧅 Sistem Rekomendasi Waktu Tanam Bawang Merah (Machine Learning)

Proyek ini adalah sistem berbasis Machine Learning yang membantu petani di Sukomoro, Nganjuk, untuk menentukan waktu terbaik menanam bawang merah berdasarkan kondisi cuaca, sehingga dapat meminimalkan risiko gagal panen (seperti umbi busuk).

## ✨ Fitur Utama
- **Prediksi Cerdas:** Menggunakan algoritma Random Forest untuk menganalisis curah hujan, suhu, dan kelembapan.
- **Antarmuka Web:** Aplikasi web interaktif yang mudah digunakan oleh petani.

## 🛠️ Teknologi yang Digunakan
- **Bahasa:** Python
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-Learn (Random Forest Classifier)
- **Visualisasi:** Matplotlib, Seaborn
- **Web App:** Streamlit
- **Sumber Data:** NASA POWER API (Data Historis Cuaca)

## 📊 Performa Model
- **Akurasi:** ~99.6% (pada data uji simulasi berbasis logika pertanian)
- **Metrik:** Classification Report (Precision, Recall, F1-Score)
